# Modern Chair Product Page 🪑

A modern, interactive product page showcasing the "Telford Kursi" chair with dynamic color variants and product information. This project demonstrates a sleek and responsive web design with interactive features.

## 🔗 Live Demo

Check out the live project: [Modern Chair](https://ykbeladiya.github.io/Modern_Chair/)

## 🌟 Features

- Interactive color selection with 6 different chair variants
- Dynamic product information display
- Responsive design that works on all devices
- Smooth transitions and animations
- Product specifications display
- Add to cart functionality (UI only)

## 🛠️ Technologies Used

- HTML5
- CSS3
- [Normalize.css](https://necolas.github.io/normalize.css/) - For consistent styling across browsers
- [Unicons](https://iconscout.com/unicons) - For modern icons

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ykbeladiya/Modern_Chair.git
   ```

2. Open `index.html` in your preferred web browser.

## 💡 Usage

- Click on different color swatches to view chair variants
- Toggle between "Description" and "Details" tabs to view product information
- Click "Add to Cart" to simulate cart functionality (UI only)

## 📱 Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
